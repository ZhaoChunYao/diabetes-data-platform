# Phase 4 — AWS / EKS

This folder is reserved for the cloud deployment stage. It will contain the EKS manifests and deployment notes after the local Kubernetes version is verified.

Planned mapping:

- Docker image to Amazon ECR
- Kubernetes cluster to Amazon EKS
- Persistent database storage to Amazon EBS
- Backup storage to Amazon S3
- Access control through IAM

This phase is not claimed as implemented yet.
