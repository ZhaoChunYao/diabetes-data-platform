# Phase 3 — Kubernetes

This folder is reserved for the next stage. It will contain Kubernetes manifests for the Dockerized application and PostgreSQL deployment, followed by a local failover test.

Planned evidence:

- Flask runs as a Deployment and is reached through a Service.
- PostgreSQL runs with persistent storage.
- Configuration and credentials are represented with ConfigMaps and Secrets.
- A restart or database failover is tested and documented with actual logs.

This phase is not claimed as implemented yet.
